## 소개

**ElementTD**는 타일에 부여된 원소 속성 위에 타워를 배치하면, 그 타일의 원소에 맞는 공격 속성과 고유 효과가 즉시 적용되는 시너지 시스템을 중심으로 설계한 타워 디펜스 게임입니다.

같은 타워라도 **어떤 타일 위에 서 있는지**에 따라 데미지 속성과 강화되는 스탯이 달라지고, 몬스터마다 원소 상성(약점/저항)이 존재해 상황에 맞는 타워 배치 전략을 요구합니다.

## 핵심 기능

- **원소 타일 시너지** — 5원소(Water / Fire / Grass / Dark / Light), 타일 위 타워의 공격 속성과 고유 효과가 실시간으로 결정
- **원소 상성 시스템** — Water → Fire → Grass 삼각 순환 + Light ↔ Dark 대립, 약점 150% / 저항 50%
- **타워 7종, 공격 방식 4가지** — 유도탄(기본) · 유도탄+가로채기(연사) · 고정 좌표 투사체(범위, 빗나감 가능) · 히트스캔(저격)
- **몬스터 16종** — 3원형(일반 / 빠른 / 탱키) × 5원소 변종 + 보스, 프리팹 1개로 런타임 데이터 주입 처리
- **방어력 & 방어관통** — 고정 수치 방어력과 원소별 방어관통 비율로 카운터 구조 형성
- **경제 시스템** — 구매 · 판매 · 강화 · 재배치, 강화 상태는 재배치 후에도 유지
- **버프/디버프 오라 중첩** — 다중 오라가 정확히 중첩되고, 하나가 사라져도 나머지는 유지 (자세한 설계 과정은 아래 참고)
- **웨이브 자동 스케일링, 배속(1/2/4배속)/일시정지, 게임오버·클리어 자동 판정**

## 아키텍처 하이라이트

- **SO(ScriptableObject) 기반 데이터 설계** — 타워 · 몬스터 · 원소 · 스테이지 데이터를 전부 SO로 분리해, 콘텐츠 추가와 수치 조정이 코드 재컴파일 없이 가능
- **전략 패턴 기반 타겟팅** — 타겟팅 알고리즘을 SO 에셋으로 분리해 인스펙터에서 알고리즘 자체를 교체 가능
- **정적 레지스트리 패턴** — 콜라이더 기반 탐지가 타일 판정과 충돌하는 문제를 발견하고, 물리 엔진 의존 없이 활성 타워/몬스터를 조회하는 구조로 재설계
- **런타임 데이터 주입** — 몬스터는 프리팹 1개가 `Initialize()`로 데이터를 주입받아 16종을 전부 처리 (추후 오브젝트 풀링 적용을 염두에 둔 설계)
- **AttackPayload 구조체** — 투사체 도입 시, 발사 시점에 확정되는 값(기본 데미지 · 원소 · 치명타 여부)과 명중 시점에 계산되는 값(대상 저항 배율)을 분리해 시간차가 있는 명중에서도 일관된 데미지 계산을 보장

## 가장 어려웠던 문제 — 오라 버프/디버프 중첩

### 문제
- 타워를 강화해도 이미 버프를 받은 대상에는 반영되지 않음
- 오라 두 개의 범위가 겹쳐도 나중 오라 값으로 덮어써져 중첩되지 않음
- 겹친 오라 중 하나를 판매하면 다른 오라의 효과까지 함께 사라짐

### 원인
대상이 버프 수치를 **단일 값 하나로만 저장**해, 어떤 오라가 얼마를 기여했는지 구분할 방법이 없었습니다.

### 해결
대상마다 **오라(발신자)별 기여도**를 저장하는 `Dictionary<AuraEffect, float>` 구조로 전환하고, 매 프레임 범위 안의 모든 오라가 자신의 최신 수치로 값을 다시 갱신하도록 설계했습니다.

- **버프** — 합산 누적
- **디버프(이동속도 감소)** — 곱셈 누적, `(1-a) × (1-b) × ...` 방식으로 오라가 아무리 많이 겹쳐도 수학적으로 이동속도가 0 이하가 될 수 없음

### 결과
강화 수치 즉시 반영, 여러 오라의 정확한 중첩, 오라 하나 제거 시 나머지 효과 유지 — 테스트로 검증 완료.

> 이 경험으로 **"여러 주체가 동시에 영향을 주는 상태는 단일 값이 아니라 출처별 기여도로 관리해야 한다"**는 설계 원칙을 체득했습니다.

## 프로젝트 구조

```
Assets/Scripts/
├── Combat/          # 데미지 계산, 투사체, 타격 이펙트
├── Core/            # 경제, 생명력, 게임 속도, 게임오버/클리어 등 전역 매니저
├── Data/
│   ├── Elements/    # 원소 효과, 색상 팔레트 SO
│   ├── Monsters/    # 몬스터 데이터, 원소 상성 규칙 SO
│   ├── Stages/      # 스테이지/웨이브 데이터 SO
│   └── Towers/      # 타워 데이터, 강화 데이터 SO
├── Monsters/        # 몬스터 로직
├── Stages/          # 스테이지 로드, 웨이브 스폰, 원소 타일 생성
├── Towers/          # 타워 로직, 전투/오라/경제 컨트롤러
└── UI/              # HUD, 상점, 툴팁, 액션 패널 등
```

개인 포트폴리오 목적으로 제작된 프로젝트입니다.
